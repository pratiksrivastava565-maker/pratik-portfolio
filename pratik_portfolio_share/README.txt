PRATIK SRIVASTAVA — PORTFOLIO WEBSITE

This is a complete standalone responsive portfolio website.

HOW TO PREVIEW
1. Extract the ZIP folder.
2. Open index.html in Chrome, Safari or Edge.
3. For best video playback, serve the folder with a local web server (e.g. VS Code Live Server) or upload the full folder to a static hosting provider.

WHAT'S INCLUDED
- Responsive portfolio home page
- Intermediate motion: intro loader, masked headline reveal, scroll reveals, staggered project cards, hover zoom, animated marquee, subtle cursor, animated project viewer
- All seven projects
- Full-length video playback for The Immortal Suryavanshi, Kartikeya and World War III
- Aether Coffee full brand-book PDF
- Social links and email contact

IMPORTANT
The three motion/explainer videos are the full uploaded 1920x1080 source videos converted to browser-friendly H.264 MP4. The viewer uses contain sizing so the full frame is visible and not cropped.
The illustrated magazine-style profile artwork is intentionally not used in this design.

This ZIP is a standalone HTML website package, not a native editable Framer project file. Framer does not import a complete HTML ZIP as editable layers. You can host this package as a website, or use the design as a reference to rebuild in Framer.
