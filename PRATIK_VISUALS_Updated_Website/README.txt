PRATIK VISUALS — PORTFOLIO WEBSITE
=================================

This is the complete static website package for:
https://pratikvisuals.netlify.app/

PREVIEW LOCALLY
1. Extract this folder.
2. Open index.html in a browser.
3. For best results, run it with VS Code Live Server or another local static server.

DEPLOY TO NETLIFY
1. Upload the complete folder to your Netlify site, or push the contents to the connected GitHub repository.
2. Keep index.html, favicon.svg, robots.txt, sitemap.xml and the assets/ folder together at the site root.
3. After deployment, open the live website and test all project previews and the contact form.

WHAT'S INCLUDED
- Responsive portfolio with desktop and mobile navigation.
- Seven selected projects: Nyla Air Water, Aether Coffee, World War II, Kartikeya, The Immortal Suryavanshi, Spider-Man and Digital Illustration.
- Project filters and accessible project viewer.
- Reduced-size WebP versions of portfolio imagery, with original image assets retained.
- Full-length H.264 MP4 video assets and Aether Coffee brand-book PDF.
- SEO title/description, Open Graph metadata, canonical URL, structured Person data, robots.txt and sitemap.xml.
- Netlify Forms markup for portfolio enquiries.
- Subtle motion, scroll reveals, reduced-motion support and keyboard-accessible controls.

CONTACT FORM
The form uses Netlify Forms markup. It needs to be deployed through Netlify for submissions to be collected.
After deployment:
1. Open Netlify dashboard > your site > Forms.
2. Confirm that the form named "portfolio-enquiry" is detected after the first production deploy.
3. Submit a test enquiry from the live website.
4. Configure form notifications in Netlify if you want email alerts.
